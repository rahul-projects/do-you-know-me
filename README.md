Create a game/app for a child of 6 years of age with following requirements.
# Game plan

- it will be a guessing game where child has to guess the number, place, things (car, aeroplane, appliances names etc.) based on the clues (in terms of questions or pictures) given or shown.
- avoid keyboard inputs, rather display the choices clearly (should not be ambiguous as well as should not be quite obvious)
- child should not get discouraged if guess is wrong. if possible child should be given more clues so he/she can reaches to the answer
- there will be difficulty levels and as game progresses the levels should get opened up
- there can be attempts counter
- replay button should not show the same clues/hints
- create at least 10 levels to begin with

# Aesthetics

- the overall look and feel should be appealing and pleasing to a child of 6 years
- it should enhance and encourage learning to the child
- if possible, there should be sound affects and animations
- if possible, include some cartoon characters

# Technology

- it should be built as Progressive Web App so that it can be saved as an Android app
- there should be some good icons shown when saved as android app
